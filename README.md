**Giphy Based On Mood App **

This Flask app, created with the help of AI, prompts the user to enter how they are currently feeling. It then brings them to a page the generates a random Giphy based on their input. At the bottom of that page there is an option to enter another mood based on how the user wishes to feel which then brings them to a second page revealing a second Giphy based on how the user desires to feel.
